# Decision Requests are surface-agnostic

The graph never knows where a Hub Operator sees a Decision Request. It pauses with a neutral payload (what it proposes, the supporting material, the allowed choices), and a thin adapter renders it: our own frontend for the pitch demo (ADR 0006; Agent Inbox was dropped), Slack (including its mobile app) for production. We chose this over building straight against one UI so that moving from the pitch frontend to Slack is a new adapter, not a rewrite — and dropping Agent Inbox cost nothing. Don't "simplify" by putting Slack or frontend specifics into graph nodes.
